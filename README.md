# Employee Payroll System in C

## Project Description

A simple C program to calculate an employee's net salary using basic salary, allowance and deduction.

## Features

- Enter employee details
- Calculate net salary
- Display salary details

## Technologies Used

- C
- Structures
- Variables
- Arithmetic operations

## How to Run

Compile and run the `employee_payroll.c` file using a C compiler.
